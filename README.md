# Walker Showcase

Walker is an accessibility-first digital companion project intended to help Deaf and Hard-of-Hearing users in Saudi Arabia communicate through Saudi Sign Language.

Mission: Saudi Sign Language → verified Arabic meaning → useful response.

WalkerAI-Hushwave is a provisional project name used in the permission correspondence; final branding has not been decided.

## Current status — updated October 29, 2026

- Stage: foundation and data-independent preparation; not a demonstrated Saudi Sign Language product.
- Isharah permission requests: sent on October 23 and October 24, 2026.
- Decision: awaiting the Isharah team's written response. No written approval was found in the email results reviewed for this update.
- Data access, training, derived-data use, model distribution, and commercialization remain blocked pending applicable written permission.
- This public showcase records progress; it does not grant a dataset license or certify product readiness.

## Latest permission-request action

The project founder sent an initial Arabic permission request on October 23 and a more detailed request on October 24. The requests cover:

1. Training and evaluating Saudi Sign Language recognition models.
2. Extracting and storing hand, face, and body landmarks and other numerical features, including with tools such as MediaPipe.
3. Local, secured development and data handling.
4. Whether a future commercial version and derived models may be permitted, and under what conditions.
5. Required agreements, attribution, preferred citation/BibTeX, and a possible discussion with the dataset team.

Requested scope is not approved scope. The project will respect the team's decision and use only what is explicitly permitted in writing. Original videos will not be republished, sold, rented, or hosted; participant identification and third-party data sharing are not intended uses.

## Doctrine

- Product proof requires real Saudi Sign Language input → accepted model prediction → verified Arabic meaning → useful Walker response.
- Camera access, hand detection, landmarks, generic gestures, avatars, status panels, canned responses, and synthetic tests alone are not product proof.
- No Isharah data acquisition, storage, training, redistribution, or derivative use is authorized until applicable permission is verified.
- No substitute ASL datasets, generic gestures, or guessed labels may stand in for the designated Saudi Sign Language source.
- Continue only data-independent architecture, documentation, validation, and synthetic contract testing while awaiting the decision.
- The project is local-first and is not intended to replace human interpreters.
