# WalkerAI-Independent-

Walker helps Deaf and Hard-of-Hearing users communicate through sign language.

**Mission:** move the user from **Saudi Sign Language → Meaning → Response**.

## Doctrine
- Product proof is only: real Saudi Sign Language input → accepted model prediction → verified Arabic meaning → useful Walker response.
- Camera access, hand detection, landmarks, generic gestures, mouse gestures, avatars, status panels, and canned responses are **NOT product proof**.
- No data is downloaded, trained, stored, or redistributed until written permission is granted by the designated source (Isharah).

## Current Status
- **Stage:** Foundation.
- **Data:** Blocked pending Isharah commercial licensing inquiry.
- **Code:** Legacy prototypes exist in the repo but are strictly experimental. They are not the product.
- **Infrastructure:** Local Linux environment on mobile is operational.
